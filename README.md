# platwyp

System przewidujący wypadki drogowe na danej trasie przejazdu. 
Wykorzystuje informacje m.in. o dotychczasowych wypadkach, natężeniu ruchu i warunkach pogodowych. Projekt niegotowy, prace trwają.
Przy tworzeniu projektu udział biorą Mateusz Witkowski, Miłosz Przymusiński, Paweł Kopytek, Rafał Bartosik, Aleks Stępniak.

System będzie integrować dane z następujących obszarów: 
dane historyczne o wypadkach i kolizjach drogowych 
aktualne warunki meteorologiczne 
informacje o natężeniu i charakterystyce ruchu drogowego 
parametry infrastruktury drogowej 
 
Wynikiem działania systemu będzie dynamiczna mapa ryzyka, aktualizowana w czasie rzeczywistym, która może służyć jako narzędzie wspierające bezpieczeństwo ruchu drogowego. 
Użytkownik może używać narzędzia aby wskazać optymalną drogę do celu nie tylko pod względem czasu ale bezpieczeństwa. 
Inspiracją do projektu jest system FeGiS mający zapobiegać wypadkom drogowym w Niemczech którego można przetestować pod tą stroną: 
https://www.gefahrenstellen.de/
